Entry for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty. The entry is one post of your own on X that quotes make.fun's make-your-own-bounty post (or links to it), with a photo of its own attached and make.fun plus your play code in its text. This repository hands the post's address to the gate: main.ts (Node 22, standard library only) copies POST.json from the repository root into the output directory, where the gate reads it.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
